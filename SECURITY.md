# Security Policy / سياسة الأمان

## Supported version
The current `main` branch is supported.

## Model
The application is local and makes no network requests. Policies can select local executables and arguments, so treat policy files as code-adjacent configuration and review untrusted files before use. Environment-variable values are intentionally never reported.

## Reporting
Please report security concerns privately through GitHub's repository security reporting facilities when available. Do not publish credentials or exploit details in a public issue.

## العربية
الأداة محلية ولا تجري اتصالات شبكة. ملف السياسة يستطيع تحديد برنامج محلي ومعاملاته، لذلك راجع الملفات غير الموثوقة قبل تشغيلها. لا تعرض الأداة قيم متغيرات البيئة. أبلغ عن الثغرات عبر قنوات GitHub الأمنية الخاصة عند توفرها، ولا تنشر أسرارًا في Issue عامة.
