# Contributing / المساهمة

Thanks for improving Dev Environment Checker. Create a focused branch, keep runtime dependencies minimal, add or update tests for behavioral changes, run `python -m unittest discover -s tests -v` and `python -m compileall -q src tests`, then open a focused pull request. Do not commit credentials, machine-specific paths, generated environments, or real secret values in sample policies.

شكرًا للمساهمة. اجعل التغييرات محددة، وأضف اختبارات للسلوك الجديد، وشغّل الاختبارات وفحص التجميع قبل فتح Pull Request. لا تضف أسرارًا أو مسارات شخصية أو قيم متغيرات بيئة حقيقية.
